# Private macOS ARM64 DMG

Дата: 21 июля 2026 года

## Цель

Добавить закрытый способ передачи Telegram Companion владельцу Mac с Apple Silicon без Apple Developer ID и notarization. Существующий публичный канал, офлайн-лицензия, Sparkle EdDSA и будущий нотарифицированный выпуск остаются без изменений.

## Решение

- Приватная сборка использует тот же канал `public-macos-arm64`, версию, лицензионный public key и appcast URL.
- Все исполняемые файлы, Sparkle XPC-компоненты, framework и приложение подписываются ad-hoc подписью строго изнутри наружу.
- Hardened Runtime и timestamp в приватном режиме не включаются, чтобы ad-hoc сборка могла загрузить вложенный Sparkle framework.
- В DMG находятся приложение, ссылка на `/Applications` и русская инструкция первого запуска.
- Первый запуск подтверждается штатно через `Системные настройки -> Конфиденциальность и безопасность -> Всё равно открыть`. Удаление quarantine через `xattr` документируется только как запасной путь для проверенного файла.
- Глобальное отключение Gatekeeper запрещено.
- Обновления остаются подписанными отдельным Sparkle EdDSA-ключом. Нативное обновление ad-hoc сборки окончательно проверяется на реальном Mac; до этого ручная замена приложения новым private DMG остаётся безопасным резервным сценарием.

## Разделение пайплайнов

- `release-public-macos-arm64`: Developer ID, notarization, stapling и Gatekeeper assessment.
- `build-private-macos-arm64`: сборка, ad-hoc подпись, private DMG и локальная проверка без Apple credentials.
- `release-private-macos-arm64`: дополнительно подписывает Sparkle-архив, публикует release assets и appcast только после явного подтверждения.

## Проверка

Статические Go-тесты контролируют отсутствие `--deep`, Apple credentials и notarization в private-пути, порядок подписи, наличие инструкции и неизменность публичного пайплайна. Финальная проверка запуска, Gatekeeper и обновления N -> N+1 выполняется на Apple Silicon Mac.
