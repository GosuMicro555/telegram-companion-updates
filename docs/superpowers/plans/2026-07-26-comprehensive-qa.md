# Telegram Companion 0.8.0 Comprehensive QA Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Проверить установленную macOS arm64-сборку Telegram Companion 0.8.0, исправить воспроизводимые дефекты и подтвердить ключевые сценарии без воздействия на посторонние Telegram-чаты.

**Architecture:** Проверки разделены на безопасный статический и автоматический контур, ручной UI-контур через TightVNC и ограниченный live-контур в единственной тестовой группе «Трое в лодке Chat». Исправления выполняются от воспроизводящего теста к минимальному изменению и полному регрессу.

**Tech Stack:** Go 1.26, Wails 2.13, React 19, TypeScript 7, Vitest, SQLite, gotd/MTProto, Sparkle, Tor/Snowflake, ONNX.

## Global Constraints

- Не удалять реальные пользовательские данные, tdata-сессии и настройки.
- Не выполнять git push, публикацию релиза или деплой.
- Не использовать другие Telegram-чаты, кроме «Трое в лодке Chat».
- Live-тесты ограничить несколькими уникальными тестовыми сообщениями.
- Не запускать массовую рассылку и не менять рабочие лимиты отправки.
- Секреты, ключи, пароли и `.env` не выводить в отчёт.
- Все найденные дефекты исправлять через TDD после подтверждения первопричины.
