# Telegram Companion v0.4.1 Implementation Plan

**Goal:** Ship the approved v0.4.1 patch from the current v0.4.0 candidate without importing v0.3.0 code or changing Telegram sending behavior.

## Global constraints

- Preserve accounts, tdata sessions, roles, channels, settings, shared reply, and working Telegram triggers.
- Use the current v0.4.0 candidate as the only source tree.
- Keep the light theme as default and retain the existing dark theme.
- Keep analytics state per tab: order, width, visibility, sort, and page size.
- Release and both Ubuntu launchers must execute one verified v0.4.1 binary.

## Task 1: Stabilize the v0.4.0 baseline

- Regenerate typed Wails bindings for the current Go surface.
- Run frontend tests/build and Go tests before feature edits.
- Record the verified candidate as the v0.4.1 base.

## Task 2: Analytics layout and table behavior

- Put START, STOP, and Analyze in one row.
- Reserve width for the next-collection timestamp, narrow the word/group metrics, and expand the table viewport.
- Make column resizing update the real grid live and persist all per-tab preferences.
- Preserve the active tab, search, sorting, and table preferences after classification.

## Task 3: Bulk classification and canonical families

- Add positive/negative bulk-input modal with text/file input, preview counts, validation, and localized errors.
- Add typed Wails DTOs plus one transactional Go operation for validated canonical upserts.
- Add conservative Russian alias families for `бабки` and `деньги`; preserve manual attach/detach precedence.

## Task 4: Statistics and branding

- Add real repository aggregates, time series, and account/channel rows.
- Replace the legacy cards with compact metrics, date-range activity chart, and sortable paginated table.
- Apply the turquoise brand color and one matching lightweight local icon.

## Task 5: Release metadata and Ubuntu install

- Update frontend, Wails, package metadata, tests, and release notes to v0.4.1.
- Add an atomic user-local installer that verifies SHA-256 and updates desktop/menu launchers to the same binary and icon.

## Task 6: Verification and deployment

- Run all frontend and Go tests plus production build.
- Deploy to Ubuntu and verify both launchers, version, layouts, imports, table persistence, analytics collection, and existing trigger replies.
